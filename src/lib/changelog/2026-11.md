#### Games page

Community projects now live on a [games page](/games), replacing the dropdown in the Import / Export menu. Each game shows a preview, a short description and who made the insert. Click one to open it in the editor. [#103](https://github.com/Siege-Perilous/counterslayer/pull/103)

#### Standee tray rows

Standee trays can now be split into **rows** that share a dividing wall, saving space over separate trays. [#101](https://github.com/Siege-Perilous/counterslayer/pull/101)

#### Layers are now sections, which can be arranged in 3D space

Layers are now **sections**, and can now we arranged within 3D space using full 6-axis movement. This allows you to position mixed-height sections next to each other. A project now carries a height, so you can arrange withing a bounding box of your physical game. Lastly, there is now a "reserved space" tray which does not generate STLs, but "fills space" in the visualization for things like game boards and manuals. [#97](https://github.com/Siege-Perilous/counterslayer/pull/97)

#### Fixes

- Tightened standee tray clearances, so existing standee trays may change size slightly. [#101](https://github.com/Siege-Perilous/counterslayer/pull/101)
- Dark mode is now the default for new visitors, whatever the browser's color scheme preference. The light / dark toggle still remembers your choice. [#103](https://github.com/Siege-Perilous/counterslayer/pull/103)
