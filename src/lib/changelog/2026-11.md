#### Layers are now sections, which can be arranged in 3D space

Layers are now **sections**, and can now we arranged within 3D space using full 6-axis movement. This allows you to position mixed-height sections next to each other. A project now carries a height, so you can arrange withing a bounding box of your physical game. Lastly, there is now a "reserved space" tray which does not generate STLs, but "fills space" in the visualization for things like game boards and manuals.
